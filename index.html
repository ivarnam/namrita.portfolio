About Me

The researcher behind the tools.

I am a PhD researcher at the Indian Institute of Technology Bombay, working at the intersection of formal methods and machine learning. My advisors are Prof. Ashutosh Gupta and Prof. Krishna Shankaranarayanan.

My work asks a deceptively simple question: can we mathematically prove that an AI system will behave as intended? I develop algorithms and tools that bring the rigor of formal verification to modern ML — particularly tree ensemble models like XGBoost and gradient-boosted trees used in high-stakes decisions.

Research AreaFormal methods for ML, trustworthy AI, verification of decision tree ensembles, runtime robustness monitoring, and specification learning.

Data-aware counterexample search
01 · ICLR 2026

Ensense

MILP + SMT-based sensitivity verification for XGBoost tree ensembles. Data-aware search uses a product-of-marginals objective with clause summaries for scalability.

GurobiZ3XGBoostPython
// MILP encoding: sensitivity query
minimize Σᵢ w(xᵢ) · |f(x) − f(x′)|
subject to ‖x − x′‖∞ ≤ δ
solver: Gurobi (MILP) + Z3 (SMT)
objective: product-of-marginals P(x)

Clause summaries reduce solver complexity without sacrificing soundness — compact representations of subtree constraints enabling scalable verification.

Related paper · arXiv:2602.07453 →
Streaming robustness monitor
L̂ = max |f(x) − f(x′)| / ‖x − x′‖
output: [L_lower, L_upper] anytime
data: observed input-output pairs only
02 · Runtime Monitoring

RobQuant

Runtime monitoring framework computing anytime lower/upper bounds on Lipschitz robustness scores over streaming input-output pairs using k-NN search.

Faissscikit-learnPythonk-NN
// Lipschitz bound computation
L̂ = max |f(x) − f(x′)| / ‖x − x′‖
k-NN: Faiss approximate search
output: [L_lower, L_upper] anytime

Works purely from observed input-output pairs — no model access needed. Bounds tighten as more data streams in.

Glitch region detector
03 · Formal Verification

ViKriTi

Detects and formally characterises glitch regions — abrupt output oscillations — in gradient-boosted decision tree ensembles using MILP encoding.

GurobiXGBoostLightGBMPython
// Glitch region detection
glitch(x) ≡ ∃ x′ ∈ Bδ(x):
  sign(f(x)) ≠ sign(f(x′))
encoding: MILP via Gurobi

First formal study of glitches in XGBoost/LightGBM — predictions that flip unpredictably in tiny input regions. Detection is provably sound via MILP.

Related paper · arXiv:2507.14492 →

04 · LTL Synthesis

Janak

Integrates LLMs with LTL solvers — LLM-generated candidates seed fitness-aware search to synthesise temporal logic specifications from demonstrations and natural-language explanations.

ChatGPT APILTL SolversPythonFormal Specs
// LTL synthesis pipeline
input: demos τ₁…τₙ + NL explanation e
LLM: candidate φ̂ seed
output: φ* s.t. ∀τᵢ: τᵢ ⊨ φ*

LLM seeds dramatically reduce search space for LTL solvers — making specification synthesis practical for robot planning and autonomous systems.
